_Telegram_-бот для управления событиями календаря на Django и PostgreSQL.
Проект позволяет создавать, просматривать, редактировать, удалять и публиковать события, а также приглашать пользователей по @username.

**Возможности**
Регистрация пользователя через /start.
Создание событий в личный календарь.
Просмотр списка событий.
Просмотр одного события по названию.
Редактирование и удаление событий.
Приглашение пользователей в событие по @username.
Подтверждение или отклонение приглашения.
Публикация событий в общий список.
Экспорт событий в CSV.

**Технологии**
Python 3.12.
Django.
PostgreSQL.
pyTelegramBotAPI (telebot).
Docker и Docker Compose.

**Команды бота**
/start — регистрация пользователя и вывод главного меню.
/create_event <название> <дата> <время> <описание> — создание события.
/add_main <название> <дата> <время> <описание> — создание события.
/list_events — список событий.
/read_event <название> — поиск события.
/edit_event <название> <новая_дата> <новое_описание> — редактирование события.
/delete_event <название> — удаление события.
/invite @username <название_события> — приглашение пользователя.
/accept_<id> — подтверждение приглашения.
/decline_<id> — отклонение приглашения.
/calendar — просмотр личного календаря.
/public_events — список публичных событий.
/publish_<id> — сделать событие публичным.
/unpublish_<id> — скрыть событие из публичного списка.
/export_events — выгрузка событий в CSV.
/test — проверка профиля в базе.
/debug_events — отладочная информация.

**Логика работы**
При первом запуске /start бот создаёт запись пользователя в базе данных, если её ещё нет.
Далее события сохраняются в PostgreSQL и могут быть изменены через команды бота.
Пользователь может приглашать других участников, а также публиковать свои события в общий список.
